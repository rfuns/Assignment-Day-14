Membuat Sistem Checkout Produk Sederhana
Program menerima tiga input: harga produk, jumlah produk, dan status member. Program kemudian menghitung subtotal, diskon, ongkos kirim, serta total pembayaran dengan aturan berikut.
Harga produk harus berupa angka positif dan jumlah produk harus berupa bilangan bulat positif. Jika tidak valid, program menampilkan pesan input tidak valid dan tidak melanjutkan perhitungan.
Subtotal = harga produk x jumlah produk.
Member mendapatkan diskon 10% dari subtotal. Non-member tidak mendapatkan diskon.
Setelah diskon, ongkos kirim gratis apabila total setelah diskon minimal Rp250.000. Jika kurang dari Rp250.000, ongkos kirim Rp15.000.
Total pembayaran = total setelah diskon + ongkos kirim.
